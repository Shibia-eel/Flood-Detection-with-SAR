FLOOD DETECTION WITH SAR: A REVIEW OF TECHNIQUES AND DATASETS

About the Project

This project focuses on reviewing techniques and datasets used for flood detection using Synthetic Aperture Radar (SAR) images. SAR technology helps detect floods by capturing images of the Earth's surface, including during cloudy weather and at night.

The project reviews different approaches used in flood detection and explores how SAR data can help identify flood-affected areas.

Objective

The main objective of this project is to study flood detection techniques using SAR images and review the datasets available for flood mapping and analysis.

Introduction

Floods are natural disasters that can cause serious damage to agricultural lands, houses, roads, and other infrastructure. Identifying flood-affected areas quickly is important for disaster management and relief activities.

Synthetic Aperture Radar is a remote sensing technology that uses radar signals to capture information about the Earth's surface. Unlike optical satellite images, SAR images can be collected during cloudy conditions and at night, making them useful for flood monitoring.

Project Scope

This project reviews existing techniques and datasets used for flood detection with SAR imagery. It focuses on understanding how SAR data can support flood mapping, identifying affected regions, and improving flood monitoring.

Applications

Flood detection using SAR can support disaster management, agricultural damage assessment, emergency response, flood mapping, and environmental monitoring.

Future Scope

Future work can explore improvements in SAR-based flood detection techniques, the use of advanced image processing and deep learning methods, and the development of more accurate flood mapping systems.
